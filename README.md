## Как выложить

1. Распакуй архив — внутри папка `zwischen` (девять файлов).
2. Открой на GitHub репозиторий, где лежит «Vorträge 1A» (`Prezent`).
3. **Add file → Upload files** → перетащи в окно **всю папку** `zwischen` целиком (не файлы по одному) → **Commit changes**.
4. Через минуту-две открой `https://kirujka.github.io/Prezent/zwischen/`.
5. На телефон — как обычно: Safari → «Поделиться» → «На экран „Домой“» (Android: Chrome → «Установить приложение»).

Утверждённое приложение в корне не трогается: у промежуточного свой кэш и свои настройки, удаляет он только собственные старые кэши.

## Обновление

Когда тексты поменяются, заливаешь новый `data.js` в ту же папку `zwischen`, а в `sw.js` меняешь `v1a-zwischen-v1` на `v1a-zwischen-v2`.

## Пометки в текстах

- ★ — новое или пересобранное предложение, к корректору.
- Б1–Б16 — общие блоки, звучат одинаково в нескольких темах; номера совпадают с PDF.
- Р1–Р5 — рамки (повторяющиеся начала предложений).
- Новые слова на вкладке «Слова» стоят в конце, произношение у них ещё не записано.
